NAME
       version - get the library version

LIBRARY
       Codata library (libiapws, -liapws)

SYNOPSIS
       Fortran   function version()result(fptr)

                    character(len=:), pointer :: fptr

       C         char* iapws_version()

       Python    str:pyiapws.__version__

DESCRIPTION
       Get the library version.

RETURN VALUE
       pointer   Pointer to the version string.

EXAMPLE
       Fortran:
           use iapws
           print *, "version = ", version()

       C:
           include <stdio.h>
           include "iapws.h"
           printf("version = %s\n", iapws_version());

       Python:
           import pyiapws
           print(f"version = {pyiapws.__version__}")
